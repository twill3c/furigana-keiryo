三つの軸第一軸が支配因子。第二・第三はその残差

振り仮名の振り方は、まず「どれだけ振るか」という一本の量に支配されている。 優しさも記憶への配慮も、その一本に引きずられる。だから支配因子と直交する軸を探すのをやめ、 それ自体を第一軸として名指しし、残りを明示的な残差にした。

第一軸

総ルビ傾向

漢字の出現のうち、ルビが振られた割合。作家ごとの文体でもあり、時代と版元の慣行でもある。 この一本が他の全部を押している。

第二軸

難所への偏り

自分の総ルビ量から予測されるより、難読字に偏って振るか。 正なら難所に集中し、負なら易しい字にも均す。

第三軸

繰り返しの抑制

一度ルビを振った語が再び出たとき、振り直さずに済ますか。 正なら読者の記憶を信用し、負なら何度でも振る。

作家の分布縦 = 繰り返しの抑制 / 横 = 難所への偏り / 円の大きさ = 総ルビ傾向

二つの残差は互いにほぼ独立(r = −0.119)なので、この平面には情報がある。 どちらの残差も総ルビ傾向とは構成上まったく相関しない(r = 0.000)が、 それは回帰の帰結であって成果ではない。意味があるのは、 この残差が作家ごとに再現することのほうである。

三分類は計量に使ったものと同じ経路で付けている。 救済は難読帯の字を含む基底、過剰は全部が易読帯の基底、 義務は読みがカタカナで難読とは無関係に振らざるをえないもの(骨牌《カルタ》)。 義務は両軸から外す。帯の中間にある字は中間として、どちらにも数えない。

総ルビ組版を分けたこれは作家の判断ではない

本文の全漢字にルビを振る総ルビ組版がある。密度では見分けられない (単に親切な作家と区別できない)ので、難易度への非依存で見分けた。 誰でも読める字にまで振るかどうか、である。

捨てた第二軸①「信用（放任率）」

易読漢字のうちルビを振らなかった割合。母集団が互いに素だから独立だと考えた。 実測すると総ルビ傾向との相関 r = −0.994 —— 事実上の恒等式だった。易読帯は全漢字出現の 75% を占めるので、 そこで測った率は全体の率に潰れる。互いに素であることは足りない。帯の質量が効く。

捨てた第二軸②「記憶への信用（反復率）」

母集団を「ルビが付いた語の再出現」に限れば定義から独立する、と考えた。 実測 r = −0.813。限定は交絡を条件付けるだけで、除去しない。 多く振る作家は再出現でも振る。

二度の失敗が構造を教えた。総ルビ傾向を統制すると、 優しさと記憶の相関は −0.094 まで落ちる。 つまり支配的な一次元と、互いに独立な弱い残差二つ。 支配因子は最初から見えていたのに、軸として名指ししなかったために二度追いかけ直した。

限界言えないことを言えないままにしておく

  • 総ルビの分離は不完全。 易読帯の出現が 200 未満の短編 — 作は判定できず、除外されずに残っている。
  • 義務ルビを取り切れていない。 熟字訓(今宵《こよい》)は いまも救済ルビに数えられている。判定器は作ったが、実データの無作為監査で 誤検出が半数近くあったので採用しなかった。原因は在庫が単字ルビ由来で 頻出字の音読み(全 に ぜん)が構造的に欠けること。
  • 作品単位では版の影響が支配的な場合がある。 作家の平均としては 作家を測っている（異版差の中央値 1.23 点 vs 作家間差 4.34 点）が、 同じ作品の版違いで 0.0 〜 67.1 まで開く例がある （岡田武松『北越雪譜』)。作品ごとの値を見せるなら、この幅を併記しなければ嘘になる。
  • 難読度は出現頻度の代理。 頻度が低くても文脈で読める字はある。 帯は粗く切り、細かい順位差は解釈しない。
  • コーパスは文学に偏る。 新聞・実用書を含まない。作家あたり最大 17 作の均衡設計であり、全集ではない。
  • 「優しさ」「信用」は指標に付けた名前であって、作家の心理の測定ではない。
